# SPA Purchasing (Vue) — фронтенд для мок-API «планирование закупок SPA»

Тестовое задание на вакансию Frontend-разработчика. Стек — Vue 3 (Composition API) + TypeScript
+ Pinia, поверх готового backend `mock_api_spa_procurement`.

## Запуск

```bash
npm install
npm run dev
```

По умолчанию фронтенд ходит на `http://localhost:8000` (см. `src/api/client.ts`, `BASE_URL`).

## Статус реализации

- Каталог товаров (`/api/catalog/products`) — полностью, с индикацией риска по алертам.
- План закупок (`/api/planning/procurement-plan`) — полностью, с переключением горизонта.
- Бюджеты (`/api/planning/budgets`) — полностью.
- Чат (`POST /api/chat`) — **упрощённо**: только текстовый вопрос/ответ, без вывода
  структурированных данных (`data`) из ответа — не успел сделать полноценный рендер таблиц
  внутри чата, честно отмечаю здесь.

Тестов нет — за отведённое время приоритет был на функциональность.
